# Folder Sync

Panel cho **Premiere Pro**: tự đồng bộ thư mục trên ổ đĩa (kể cả Google Drive) vào Project panel — dựng lại cây thư mục thành cây bin, import file mới ngay khi xuất hiện, không import trùng, chạy ngầm kể cả khi đóng panel.

*A Premiere Pro panel that auto-syncs disk folders (Google Drive included) into project bins — mirrors the folder tree, imports new files as they arrive, never imports duplicates, keeps running in the background.*
